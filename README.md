# Ajay Portfolio

Personal portfolio website for Ajay Kokcha, focused on iOS development skills,
projects, resume access, and contact links.

## Tech Stack

- HTML
- Tailwind CSS

## Run Locally

Open `index.html` directly in a browser, or serve the folder with a local server:

```sh
python3 -m http.server 5500
```

Then visit `http://127.0.0.1:5500/`.
